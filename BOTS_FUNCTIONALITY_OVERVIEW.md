# Перечень функционала ботов

## Бот №1 (`signal-bot-1`) — основной бот

### Пользовательская часть
- `/start`:
  - создает/обновляет пользователя в БД;
  - отправляет welcome-сценарий из нескольких сообщений;
  - показывает постоянную клавиатуру.
- Постоянные кнопки:
  - `TRADING BOT` — открывает главное меню с inline-кнопками.
  - `choose a subscription` — открывает выбор тарифа.
  - `BONUS SCANNER` — ведет в AI-бота.
- Главное меню (`TRADING BOT`):
  - `Trading cabinet` (переход в блок экосистемы),
  - `Why us`,
  - `Reviews`,
  - `Support`.
- Экосистема (`Trading cabinet`):
  - кнопка `Trading bot` (ссылка на VIP signal bot),
  - `Back to main menu`.
- Подписки:
  - выбор тарифа `$24/$100/$200`;
  - создание инвойса в Crypto Pay;
  - кнопка оплаты + кнопка `Check status`.
- Проверка оплаты:
  - получение статуса инвойса из Crypto Pay;
  - при `paid` — запись платежа и активация подписки;
  - защита от повторной обработки уже оплаченного инвойса.
- Баланс/подписка:
  - пополнение `balance`;
  - активация/продление premium по сумме платежа;
  - расчет срока подписки и `premium_until`.

### Админская часть
- `/admin` (`/admine`) — список админ-команд.
- `/stats` — пользователи, активные, платежи, сумма, split-группы.
- `/admin_list` — список админов.
- `/admin_add <id>` — добавить админа.
- `/admin_remove <id>` — удалить админа (кроме себя).
- `/send_message` — массовая рассылка текста всем пользователям (опц. кнопка-ссылка).
- `/send_notification` — шаблонная рассылка всем пользователям.
- `/cancel` — отмена текущего FSM-сценария.

### Интеграции
- Telegram Bot API (aiogram).
- Supabase PostgreSQL.
- Crypto Pay API.

## Бот №2 (`signal-bot-2`) — бот сигналов / VIP

### Пользовательская часть
- `/start`:
  - проверяет premium-статус в общей БД;
  - premium/non-premium получают разные тексты;
  - non-premium получает кнопку `Go to main menu` (в основной бот).
- Стартовое сообщение:
  - закрепляется;
  - удаляется сервисное уведомление "message pinned".
- Проверка подписки через callback:
  - `check_subscription` показывает актуальный статус.

### Админская часть
- `/admin` (`/admine`) — список админ-команд.
- `/send_signal` — мастер создания сигнала:
  - 1-2 фото;
  - выбор типа `SHORT/LONG`;
  - ввод переменных шаблона (пара, вход, плечо, цели, стоп);
  - предпросмотр перед отправкой;
  - кнопки `Cancel/Edit/Send Group 1/Send Group 2`.
- Отправка сигнала:
  - сохранение сигнала в БД;
  - рассылка только активным premium выбранной группы;
  - админы получают сигнал всегда;
  - отправка с медиа;
  - закреп у получателя + удаление системного уведомления о закрепе.
- `/summarize`:
  - выбор группы;
  - список активных premium пользователей группы.
- `/send_notification`:
  - админ вводит только время;
  - подстановка в шаблон `{time}`;
  - рассылка только `is_premium=1 AND is_active=1`.
- `/send_message`:
  - массовая рассылка произвольного текста;
  - опциональная кнопка-ссылка.
- `/cancel` — отмена активного сценария FSM.

### Интеграции
- Telegram Bot API (aiogram + FSM).
- Supabase PostgreSQL (общая с ботом №1).

## Бот с ИИ (`BonusBotGPT`) — AI Scanner

### Пользовательская часть
- `/start`:
  - приветственный текст;
  - закреп приветствия.
- Subscription-gate (опционально):
  - если задан `REQUIRED_CHANNEL`, бот пускает дальше только подписанных;
  - кнопки `Subscribe to channel` и `Check subscription`.
- Прием данных:
  - фото;
  - документ-изображение (`png/jpg/jpeg`) с проверкой mime/расширения.
- AI-анализ:
  - отправка изображения в GPT Vision (`gpt-4o`);
  - возврат структурированного анализа (trend/levels/setups/summary).
- Обработка ошибок:
  - не изображение;
  - нечитаемый график (`UNREADABLE_CHART`);
  - ошибка API.
- После ответа:
  - приглашение отправить следующий график.
- Удаление сервисного сообщения о закрепе (best-effort).

### Интеграции
- Telegram Bot API.
- OpenAI API (`gpt-4o`).
- Telegram channel membership check (`get_chat_member`).

## Общее по всей системе
- 3 отдельных Telegram-бота под разные задачи (продажа / сигналы / AI).
- Единый контур данных в Supabase (users, payments, subscriptions, signals, admins).
- Монетизация через Crypto Pay.
- Сегментация аудитории `split_group` для управляемых рассылок.
- Управление через админ-команды.
- Прод-эксплуатация через PM2.
