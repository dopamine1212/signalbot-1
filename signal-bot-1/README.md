# Telegram Bot с криптоплатежами

Телеграм-бот с интеграцией криптоплатежей и системой управления админами.

## Структура проекта

```
project signals/
├── config.py          # Настройки приложения
├── database.py         # База данных (SQLite)
├── services.py         # Сервисы (пользователи, платежи, админы)
├── handlers/          # Обработчики команд бота
│   ├── __init__.py    # Объединение всех роутеров
│   ├── start.py       # Команда /start
│   ├── profile.py     # Команда /profile
│   ├── payment.py      # Команды и обработчики платежей
│   ├── help.py        # Команда /help
│   └── admin.py       # Админские команды
├── bot.py              # Логика бота
├── main.py             # Запуск бота
├── requirements.txt    # Зависимости
├── .gitignore          # Игнорируемые файлы
└── README.md           # Документация
```

## Установка

1. Клонируйте репозиторий или создайте проект
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните необходимые переменные в `.env`:
   - `BOT_TOKEN` - токен вашего Telegram бота (от @BotFather)
   - `ADMIN_IDS` - ID администраторов (через запятую)
   - `CRYPTO_BOT_TOKEN` - токен Crypto Bot (от @CryptoBot)

## Запуск

```bash
python main.py
```

## Функционал

### Для пользователей:
- `/start` - Регистрация и начало работы
- `/profile` - Просмотр профиля и баланса
- `/payment` - Пополнение баланса через криптоплатежи
- `/help` - Справка по командам

### Для админов:
- `/stats` - Статистика бота (пользователи, платежи)
- `/admin_list` - Список всех админов
- `/admin_add <user_id>` - Добавить админа (можно ответить на сообщение)
- `/admin_remove <user_id>` - Удалить админа

## Разработка

Проект использует:
- **aiogram 3.x** - для Telegram бота
- **sqlite3** - встроенная база данных (не требует установки)
- **Crypto Bot API** - для криптоплатежей (официальный бот Telegram @CryptoBot)

## Управление админами

Админы хранятся в базе данных. При первом запуске админы из `ADMIN_IDS` в `.env` автоматически добавляются в БД.

Добавить нового админа можно двумя способами:
1. `/admin_add <user_id>` - указать ID пользователя
2. Ответить на сообщение пользователя командой `/admin_add`

## Расширение функционала

Для добавления новых функций:
1. Добавьте обработчики в соответствующий файл в `handlers/`:
   - `start.py` - для команд начала работы
   - `profile.py` - для работы с профилем
   - `payment.py` - для платежей
   - `help.py` - для справки
   - `admin.py` - для админских команд
   - Или создайте новый файл и подключите его в `handlers/__init__.py`
2. Добавьте сервисы в `services.py` при необходимости
3. Добавьте модели в `database.py` для новых сущностей
4. Все обработчики автоматически регистрируются через роутер в `handlers/__init__.py`
